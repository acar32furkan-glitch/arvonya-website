# Arvonya Website

**Modern web sitesi** — Arvonya için geliştirilmiş, yüksek performanslı, SEO-iyileştirilmiş kurumsal web uygulaması.

🌐 **Canlı:** [arvonya-site.vercel.app](https://arvonya-site.vercel.app)

---

## 🛠️ Teknoloji Yığını

| Katman | Teknoloji |
|--------|-----------|
| **Framework** | TanStack Start (SSR) |
| **Routing** | TanStack Router (file-based) |
| **UI** | React 19 + shadcn/ui |
| **Styling** | Tailwind CSS 4 |
| **State** | TanStack Query |
| **Forms** | React Hook Form + Zod |
| **Backend** | Supabase (PostgreSQL + Auth) |
| **Deployment** | Vercel |

---

## ✨ Temel Özellikler

- ✅ Full-stack TypeScript
- ✅ SSR (Server-Side Rendering)
- ✅ Responsive tasarım
- ✅ Dark mode desteği
- ✅ SEO optimizasyonu
- ✅ Real-time veri senkronizasyonu

## 🚀 Hızlı Başlangıç

### Gereksinimler
- Node.js 24+ 
- npm

### Kurulum

```bash
npm install
cp .env.example .env.local
npm run dev
```

Uygulama `http://localhost:3000` adresinde açılır.

---

## 📜 Kullanılabilir Komutlar

```bash
npm run dev          # Geliştirme sunucusu (HMR)
npm run build        # Production build
npm run preview      # Build çıktısını önizle
npm run lint         # ESLint kontrolü
npm run format       # Kod biçimlendirme
```
